# cli

`@blueprint-platform/cli` — the `blueprint` command, pinned into every generated Blueprint project's `devDependencies`. Run `npx blueprint add layout|component|module` from inside a generated project to add things after the fact.

This library was generated with [Nx](https://nx.dev).

## Building

Run `nx build cli` to build the package.

## Running unit tests

Run `nx test cli` to execute the unit tests via [Jest](https://jestjs.io).
